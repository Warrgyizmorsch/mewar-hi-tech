# Celebration banner

The banner uses Container, heading-primary, section-padding, project color tokens, and default blob-btn classes. All banner-specific responsive styling is inline Tailwind. It renders once in the shared root layout before Footer. Footer links and their order are preserved.

## Built-in image_gen assets and prompts

- public/images/celebration-25-emblem.webp: Create a standalone transparent gold 25 YEARS CELEBRATION emblem, gold laurels, three stars and ribbon, matching the supplied reference. No surrounding scene or banner; preserve padding around the full emblem.
- public/images/celebration-crushing-plant.webp: Use the supplied real plant photograph to create a high-resolution 3:2 photorealistic crushing and screening plant with cone crusher, conveyors, navy steel and mustard-yellow safety accents in an evening quarry. No emblem, text, UI or borders.
